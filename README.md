# 招聘工作台

本地 Electron 桌面软件，仅接入智联招聘。账号与岗位连接使用已验证的独立 Chrome 登录交接方式；连接完成后关闭 Chrome，后续岗位读取不需要浏览器常驻。界面借鉴竞品三个招聘模块，不显示额度提示。

## 已实现

- 账号：连接、取消登录、断开、岗位刷新、连接失效提示。
- 本地 SQLite：系统安全存储加密业务资料及登录状态；重启保留资料，暂停未完成任务。
- 智能接管：按账号/岗位管理手工录入资料，编辑简历摘要、候选人消息与草稿，人工接管，岗位事实/FAQ/待追问问题。
- 会话摘要：手动读取最近一页智联求职者会话（最多20条），按平台会话ID去重；与手工资料区分、加密保存，需人工关联岗位。仅最近消息摘要，发送方未确认，不冒充完整聊天历史。
- 在线简历：保留真实会话的简历定位信息，单独读取平台可见简历卡片，显示职业信息及可见的工作/教育经历；与手工补充经历分开加密保存。不下载或解锁附件，不等同完整简历文件。
- AI：默认使用本机已登录的 Codex 生成真实草稿，无需单独填写 API 密钥；也可选择兼容 Chat Completions 的模型服务。设置页可用虚构资料测试 Codex，不写入候选人记录。
- 历史：可按会话读取最近一页或更早历史，按消息标识去重、加密保存；消息依据已核对的发送者标识区分左右，不调用已读回执接口。最多保留1000条，不承诺全部历史。
- 身份核对：读取平台组织与招聘者标识并保存组合摘要，再次核对不一致即停止使用。
- 任务：按账号与岗位选择模板、计划数量和间隔，针对本地资料做技能文本匹配及话术草稿预演；启动、暂停、继续、停止、进度和记录。
- 话术：新建、编辑，支持 `{岗位}`、`{称呼}`。任务保存模板快照。
- 导出：用户选择路径，导出业务 JSON，不包含登录凭证或 API 密钥。

## 尚未接通的智联能力

完整聊天历史、实时消息监听、推荐人才获取和自动打招呼仍未完成；自动回复代码已实现，真实平台外发尚未验收。摘要同步、去重和重启保留已做开发验证；不主动调用已读回执接口。手工录入仍单独标注。草稿预演不会联系候选人，不能当作已实现自动招聘外发。自动打招呼外发仍在后端阻断。会话自动回复是独立入口，默认关闭，必须选择有效岗位并在会话中明确开启。

不承诺平台永不识别异常。网页登录会话复用是本次技术实现，不等于取得智联开放 API 合作授权。

## 使用

可从仓库 Releases 下载已发布的 Windows 免安装包；macOS 可通过下方命令自行构建。在账号管理中点连接账号并输入本地备注名，在弹出的 Chrome 登录招聘者账号并进入推荐人才。软件检测岗位响应后自动关闭 Chrome，验证独立读取并保存加密会话。后续自行运行默认打包命令时产物位于 `release/`。

在智能接管中录入已有候选人资料，配置岗位规则。使用 AI 草稿前在应用设置选择本机 Codex（需已安装并登录）或自定义 API；同一服务密钥留空保留已保存值，更换服务域名需重新填写。本机模型可使用 `http://127.0.0.1:端口/v1`。生成时会将所选资料（含已读取的平台可见简历卡片）、最近最多30条已读取历史及岗位规则提交给所选的 Codex 或模型服务，结果需要人工审核。

当前每次连接是一个独立本地账号备注，可通过「验证账号身份」核对平台组织与招聘者标识；同一平台账号重复连接仍会建立不同本地条目，不自动合并业务记录。断开清理凭证，业务历史保留。退出应用停止本地任务；再次启动需人工继续。

## 开发与验证

```sh
pnpm install --ignore-scripts
node node_modules/electron/install.js
pnpm typecheck
pnpm test
pnpm build
pnpm start
pnpm package:mac
# Windows x64 免安装包（未配置签名时）
pnpm exec electron-builder --win portable --x64 --config.win.signAndEditExecutable=false
```

Node 22+ / pnpm / Chrome。`pnpm dev` 只运行网页预览，不提供本地桌面能力。源码不含真实账号、Cookie 或模型密钥。`RECRUITMENT_DATA_DIR` 可把自动化验收隔离到专门测试目录，不要用于指向他人数据。

## 数据与安全边界

界面通过受限 preload 与主进程通信，不能读 Cookie、执行任意 HTTP 或访问 Node。外部页面只在独立 Chrome 打开。业务操作由 Zod 验证，智联连接器仅允许已核对的固定企业、岗位、身份、会话摘要与历史读取端点。若平台业务码为 401，则标记登录过期并暂停任务，不盲目重试。

本机业务库位于 Electron userData，SQLite 中的数据值由 Electron safeStorage 加密；同一登录用户/本机的权限边界由系统提供。导出的 JSON 是明文业务资料，妥善保存。正式跨机器分发、macOS 公证和 Windows 系统验收尚需相应发布环境。

## 附件原文件与消息方向

历史消息依据已核对的招聘者/对方发送者标识区分左右：对方在左、我方在右，无法匹配的保持待确认。旧记录重新读取历史后更新方向。

“下载附件简历”独立于在线简历卡片。软件核对当前会话和平台附件权限，仅在可直接查看且不进入已知收费/解锁分支时取得原文件地址；不代发索要消息。支持PDF、DOC和非宏DOCX，HTTPS下载上限20MiB、30秒超时，保存到使用者选择的位置。完整权限查询可能形成平台查看记录。未提供、等待回复、隐藏或需要解锁的附件会显示原因，不能从卡片摘要生成一个PDF冒充原附件。

## 会话自动回复

在智能接管选择平台会话并关联本账号仍在招聘的岗位后，可启用自动草稿或确认开启自动发送。每90秒检查一次已开启的会话，不需要Chrome常驻，不是实时IM监听。开启时建立历史基线，仅处理之后的对方新文本；连续文本合并一次回复，记录全部触发消息ID。

人工接管、暂停、岗位撤回、账号失效或资料变化会阻止后续发送。模型完成后会重新核对聊天，防止回答已过时的问题。每次提交前保存固定发送ID，结果不确定则暂停且不重发；“核对结果”只读取平台历史。平台接受请求、历史确认消息和对方已读是不同状态。退出或重启后暂停。

当前实现与隔离测试已经完成，真实Codex定时自动草稿已验证；真实候选人发送/接收仍需明确测试对象并完成独立验收。岗位状态需要结合平台页面核对；当前实现会阻止对撤回等停招状态的岗位开启自动回复。不要把测试通过或“检查发送权限”通过当作真实发送成功。

### 大模型配置与知识库（2026-09-17）

在「应用设置」选择在线模型、本地模型或本机 Codex。
- 在线模型：填写兼容 OpenAI Chat Completions 的基础地址、模型名、密钥，点击「测试当前配置」。测试使用当前表单，不自动保存密钥；更换服务域名不会带上旧密钥。
- 本地模型：选择 Qwen 2.5 3B 或轻量测试用 0.5B，点击「一键下载安装并配置」。软件下载固定版本 Ollama 0.34.1 官方包，SHA-256 校验后安装到应用数据目录，不要求系统管理员安装。可取消并重新开始；模型分片由 Ollama 续传。只监听 127.0.0.1:11435，退出软件停止自有进程。macOS 实测，Windows 分支需在 Windows 验证。
- 模型测试：可选岗位并填写问题，查看真实模型回答及本次检索片段；不向求职者发送消息。测试成功代表能生成，不代表回答事实已经正确。

左侧「公司与岗位知识库」可新增、编辑、删除文本资料。公司资料共享给同一招聘账号下的岗位；岗位资料仅供指定岗位使用，不跨账号。现阶段支持粘贴文本，不包含 PDF/Word 文档解析。知识保存在现有加密数据中，导出时包含知识资料。

检索采用中文双字词 BM25，问题相关片段最多 6 条、合计 4800 字，附资料标题与范围送入模型；手动草稿和自动回复共用检索。岗位既有规则仍全量提供。知识或规则在自动生成期间变化时，旧结果不会继续发送。没有匹配资料时返回空检索结果，提示模型确认事实。该实现是本地词法 RAG，不依赖额外向量服务。

本地运行环境来源：https://github.com/ollama/ollama/releases/tag/v0.34.1 。模型下载协议：https://docs.ollama.com/api/pull 。
